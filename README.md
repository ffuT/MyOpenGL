# My OpenGL program
My OpenGL program is just me experimenting with OpenGL <br>
The program uses GLFW, GLEW, IMGUI, and GLM. The code is inspired by The Chernos OpenGL youtube playlist,
but has major diffrences based on my preferences and how i want to structure the code. Its a project i work on sometimes, but has no real goals other than just learning

## Build and run
It builds and runs on both windows and my linux (arch) machine

#### Windows
To build on windows for visual studio, first download premake5 <br>
in command promt type: `winget install Premake.Premake.5.Beta` <br>
then to get the visual studio project files run `premake5 vs2022` inside the directory of the project<br>

## Key Binds
Mouse1 to go into camera mode <br>
Mouse to move Camera <br>
Esc to leave camera mode, and if in window mode close program <br>
WASD to move, C to go down, Spacebar to go up <br>
Q and E to Roll camera <br>
